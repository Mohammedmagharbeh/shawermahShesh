### 🔌 في حال كانت طابعة الكاشير موصولة بـ USB (منفذ USB001):
1. افتح صفحة خادم الطباعة على جهاز الكاشير: `http://localhost:3456`.
2. ستجد قسماً يعرض **طابعات الويندوز المكتشفة على الجهاز (USB)**.
3. انسخ اسم الطابعة الظاهر (مثلاً `POS-80`).
4. في ملف `config.json`، اضبط طابعة الكاشير هكذا:
   ```json
   "cashier": {
     "name": "طابعة الكاشير",
     "type": "usb",
     "printerName": "POS-80"
   }
   ```
5. أعد تشغيل `start.bat`. ستطبع الفواتير فوراً على منفذ الـ USB دون الحاجة إلى أي عنوان IP!

## 🚀 طريقة التشغيل على جهاز الكاشير / الأدمن (Windows):

1. ادخل إلى المجلد `print-agent`.
2. اضغط مرتين على الملف:
   ```
   start.bat
   ```
3. ستفتح شاشة سوداء تؤكد تشغيل الخادم وتظهر:
   ```
   [PrintAgent] Running on http://127.0.0.1:3456
   [PrintAgent] Shawermah Printer: 192.168.1.56
   [PrintAgent] Burger Printer:    192.168.1.55
   [PrintAgent] Snack Printer:     192.168.1.57
   ```

## ⚡ كيف تعمل الطباعة التلقائية؟
- بمجرد ضغط الأدمن على زر **"قبول" (Accept)** في الداشبورد، يتم تحويل الطلب إلى `Confirmed`.
- يقوم النظام فوراً برسم الفاتورة بالعربي بدقة عالية وتوزيع الأصناف على الطابعات الثلاث في أجزاء من الثانية.
- تخرج الفاتورة فوراً من الطابعات بدون الحاجة لاختيار طابعة وبدون ظهور شاشة الطباعة في المتصفح نهائياً!
- يوجد أيضاً زر **"طباعة الشبكة (تلقائي)"** على بطاقة كل طلب لإعادة طباعته في أي وقت إذا نفد الورق.

---

## ⚙️ التشغيل التلقائي مع بدء تشغيل الويندوز (اختياري):
إذا أردت أن يعمل خادم الطباعة تلقائياً عند تشغيل جهاز الكمبيوتر:
1. اضغط على كيبورد الكمبيوتر: `Win + R`.
2. اكتب `shell:startup` واضغط Enter.
3. انسخ اختصار (Shortcut) لملف `start.bat` وضعه داخل هذا المجلد.
سينطلق خادم الطباعة تلقائياً في الخلفية في كل مرة يفتح فيها جهاز الكاشير!
